# 🏠 Sahayak

### Smart Home Service Platform

**Sahayak** is a smart service platform designed to connect users with **verified professionals** for easy, reliable, and hassle-free home services.

The platform aims to simplify the process of finding, selecting, and booking skilled workers for different household needs while providing a convenient digital experience for both **customers and service providers**.

---

## 📌 Overview

Finding a reliable professional for home services can often be difficult and time-consuming. Sahayak provides a centralized platform where users can discover suitable workers, explore available services, and connect with professionals based on their requirements.

The platform is designed around three major user roles:

* 👤 **Customer** – Find and book suitable professionals.
* 🛠️ **Worker** – Manage services and customer requests.
* 👨‍💼 **Admin** – Manage users, workers, services, and the overall platform.

---

## ✨ Features

### 👤 Customer

* Browse available home services
* Find verified workers
* View worker/service information
* Request or book services
* Manage bookings
* Access a personalized customer dashboard

### 🛠️ Worker

* Worker registration and authentication
* Manage professional profile
* Manage offered services
* Receive customer requests
* Manage bookings and service requests
* Access a dedicated worker portal

### 👨‍💼 Admin

* Admin dashboard
* Manage customers and workers
* Manage available services
* Monitor bookings
* Manage and verify service providers
* Platform-level management

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/aminraws/Sahayak.git
```

### 2. Navigate to the Project

```bash
cd Sahayak
```

### 3. Install Dependencies

If the frontend application uses npm:

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will then be available on the local development server.

> **Note:** The exact setup commands may vary depending on the application inside the `sahayak` directory.
